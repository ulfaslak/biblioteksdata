# Biblioteksprognose

Skillen ligger i `.agents/skills/biblioteksprognose/` i roden af repoet, så alle kodeagenter kan finde den. Læs `.agents/skills/biblioteksprognose/SKILL.md`, og følg den. Den mappe er "denne mappe" i den fil: `data.js` skrives dér, og `prognose.html` åbnes derfra.
