# Læg dine data her

Kopier bibliotekets eksporter ind i denne mappe, som `.xlsx` eller `.csv`:

- **Udlån fra Cicero**: gerne flere år, fx ét udtræk pr. halvår eller kvartal.
- **Besøg fra persontællerne**: eksporten fra jeres tællersystem, gerne pr. time.
- Andet, du vil analysere: arrangementer, åbningstider, budget, indkøb.

Brug kopier, ikke originalerne. Agenten må gerne lave nye filer her, fx resultater i `data/resultater/`.

Alt i denne mappe bliver på din computer: git ignorerer det, så det kommer aldrig på GitHub. Men det, agenten selv læser, sendes til AI-tjenesten. Læg derfor **ingen personoplysninger** her (navne, lånernumre, CPR-numre, adresser). Se afsnittet om databeskyttelse i [README](../README.md).
